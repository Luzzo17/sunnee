# Sunnee WordPress Theme

# Descrizione
Sunnee WordPress Theme e' un tema WordPress custom creato da zero per Sunnee, un brand ipotetico di costumi da bagno ecosostenibili realizzati con filati ricavati da plastica marina riciclata.

Il sito presenta il brand, la sua storia, la missione sostenibile, le collezioni e una sezione contatti. I contenuti principali del tema sono personalizzabili dal pannello WordPress tramite Customizer, mentre il form contatti e' gestito con Fluent Forms.

Come richiesto dalla consegna, il sito verra' esportato tramite il plugin All-in-One WP Migration.

# Architettura
Il progetto e' strutturato come tema WordPress custom:

Setup tema, Customizer e caricamento asset: functions.php

Header e navigazione: header.php

Footer e contatti: footer.php

Homepage: front-page.php

Template pagine: page.php, page-chi-siamo.php

Sezioni riutilizzabili: template-parts/

Stili principali e responsive: assets/css/

Interazioni JavaScript: assets/js/main.js
